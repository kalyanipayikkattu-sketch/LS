## Project Description
A useless calculator web application styled like a classic Windows window that gives humorous, sarcastic, or completely incorrect dynamic responses instead of standard math answers.

## The Problem (that doesn't exist)
Standard calculators always give predictable, correct mathematical answers, which lacks surprise and humor during tedious calculations.

## The Solution (that nobody asked for)
We created a web-based calculator disguised as a Windows window that replaces actual arithmetic results with a randomized pool of funny standard answers and witty remarks, complete with an un-closable window feature.
